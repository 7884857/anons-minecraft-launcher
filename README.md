# anon's Minecraft launcher

A decentralized Minecraft launcher — single executable, no central server required.

## Status

Repository created. Source and releases will be added here.

## Goals

- Single `.exe`, zero install dependencies on Windows 10/11
- Game versions, loaders, and mods fetched live from official sources and public mirrors
- Launcher self-update via signed manifests (anyone can mirror; only trusted keys can publish)
- No telemetry; account tokens stay on the local machine
